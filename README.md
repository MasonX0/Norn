# Norn - Система управления практикой студентов

## 📋 О проекте

**Norn** - это desktop приложение на Kotlin Multiplatform для управления практикой студентов
образовательных учреждений. Система автоматизирует процесс распределения студентов по предприятиям,
ведения документооборота и формирования отчетности.

## ⚡ Основной функционал

### 👥 Управление студентами

- База данных студентов с полной информацией
- Группировка по учебным группам
- Отслеживание статусов прохождения практики
- Индивидуальные карточки студентов

### 🏢 Управление предприятиями

- Реестр баз практики
- Контактная информация и ответственные лица
- Количество доступных мест для практикантов
- История сотрудничества

### 📄 Документооборот

- Автоматическое формирование направлений на практику
- Генерация приказов и распоряжений
- Заявления студентов
- Отчеты по практике

### 📊 Отчетность

- Сводные отчеты по группам
- Статистика распределения
- Анализ эффективности баз практики
- Экспорт данных

## 🛠 Технический стек

- **Kotlin Multiplatform** - основная платформа разработки
- **Compose Desktop** - UI фреймворк
- **Flow & StateFlow** - управление состоянием
- **Repository Pattern** - архитектура данных

## 🏗 Архитектура

```
composeApp/
├── commonMain/           # Общая бизнес-логика
│   ├── models/          # Модели данных
│   └── repository/      # Слой данных
└── jvmMain/             # Desktop UI
    ├── screens/         # Экраны приложения
    ├── navigation/      # Навигация
    └── viewmodel/       # ViewModel слой
```

## 🚀 Запуск проекта

1. Клонируйте репозиторий
2. Откройте в IntelliJ IDEA или Android Studio
3. Запустите `./gradlew run` или используйте IDE
