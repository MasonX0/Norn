# Norn - Система управления практикой студентов

**Norn** - десктопное приложение на Kotlin Multiplatform для автоматизации управления студенческими
практиками.

## Основные функции

- **Загрузка данных** - импорт списков студентов из Excel файлов
- **Управление предприятиями** - ведение баз практики с руководителями
- **Генерация документов** - создание приказов, направлений, отчетов
- **Распределение практики** - назначение студентов на базы практики

## Структура экранов

### Верхняя панель навигации

- **Информация** - основные данные о практике
- **Сводный отчет** - генерация итоговых отчетов
- **Направление** - создание направлений на практику
- **Приказ** - формирование приказов по практике

### Нижняя панель навигации

- **Предприятия** - управление базами практики
- **Студенты** - работа со списками студентов
- **Ведомости** - обработка ведомостей (в разработке)
- **Настройки** - конфигурация приложения

## Технологии

- Kotlin Multiplatform
- Compose Desktop
- Apache POI (работа с Excel/Word)

## Использование

1. Загрузите списки студентов через Excel файлы
2. Настройте базы практики и руководителей
3. Распределите студентов по предприятиям
4. Сгенерируйте необходимые документы
